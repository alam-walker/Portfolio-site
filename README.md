# Bahauddin Alam — Portfolio

Personal portfolio website of **Bahauddin Alam**, full stack developer.

- **Live:** https://portfolio-bahauddin-alam.vercel.app
- **Stack:** Next.js 15 (App Router), React, Vercel
- **Aesthetic:** 8-bit pixel-art nostalgia inspired by [alvvays.com](https://alvvays.com) — chunky pixel type (Press Start 2P + Silkscreen), brand-red wordmark, full-bleed pixelated hero, and retro OS-window modals for About / Work / Contact.
- **SEO:** metadata + Open Graph/Twitter cards, Person JSON-LD, sitemap, robots.

## Develop

```bash
npm install
npm run dev
```

## Edit content

Everything personal lives in `app/content.js` — name, role, bio, tech stack, capabilities, email and social links.

## Deploy

```bash
vercel --prod
```
